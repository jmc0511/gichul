# NAS(헤놀로지/시놀로지 DSM 7.2+)에 출제 처리기 설치

1. PC 터미널에서 `claude setup-token` → 브라우저 로그인 → 나온 `sk-ant-oat…` 토큰 복사
2. `.env` 채우기: CLAUDE_CODE_OAUTH_TOKEN, SUPABASE_URL, SUPABASE_SECRET (secret.json 과 같은 값)
3. File Station → `docker` 공유폴더 아래 `gichul` 폴더 만들고, 이 nas 폴더의 파일 전부 업로드
   (Dockerfile, docker-compose.yml, .env, package.json, queue.mjs, runner.mjs, PROMPT.md)
4. Container Manager → 프로젝트 → 생성
   - 프로젝트 이름: gichul / 경로: /docker/gichul / 소스: 기존 docker-compose.yml 사용
   - 다음 → 완료 (이미지 빌드 후 자동 시작)
5. Container Manager → 컨테이너 → gichul-worker → 로그 에서 "대기열 감시 시작" 확인

DSM 7.1 이하(프로젝트 메뉴 없음): SSH 접속 후
`cd /volume1/docker/gichul && sudo docker-compose up -d --build`

수정 후 다시 반영 (파일만 덮어쓰고 '빌드'하면 예전 이미지가 그대로 쓰이는 경우가 있음):
1. 파일 덮어쓰기 (업로드 시 '덮어쓰기' 선택)
2. 프로젝트 → gichil → 정지
3. 컨테이너 탭에서 gichul-worker 삭제, 이미지 탭에서 gichil-gichul-worker 삭제
4. 프로젝트 → gichil → 작업 → 빌드
5. 로그 첫 줄이 "처리기 시작 (실시간 알림 …)" 이고 "실시간 알림: SUBSCRIBED" 가 보이면 성공
