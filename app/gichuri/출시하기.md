# 앱 올리기 (앱 스토어 · 플레이 스토어)

`준비하기.md` 를 먼저 끝내 두세요.

## 0. 어느 계정으로 올리는지 먼저 확인

애플 개발자 계정이 둘이라면, **출시할 계정**으로 맞춰져 있는지 보고 시작하세요.

아래 명령은 모두 **`app/gichuri` 폴더 안에서** 실행합니다.

```bash
cd ~/gichul/app/gichuri            # 먼저 여기로

grep -m1 DEVELOPMENT_TEAM ios/Runner.xcodeproj/project.pbxproj
# XK8U6LB8Y8 이면 맞습니다. 다르면:
ruby tool/xcode-setup.rb --team XK8U6LB8Y8
```

Xcode 는 Settings → Accounts 에 그 계정이 있어야 하고, Runner → Signing & Capabilities 의
Team 이 그 계정으로 보여야 합니다. App Store Connect 도 그 계정으로 로그인해 앱을 만드세요.

## 0-1. 버전 정하기

`pubspec.yaml`(app/gichuri 안) 의 `version: 1.0.0+1` 에서
`1.0.0` 이 사람들에게 보이는 번호, `+1` 이 올릴 때마다 1씩 올려야 하는 빌드 번호입니다.

## 1. 아이폰 — 보관함 만들어 올리기

```bash
flutter build ipa          # app/gichuri 안에서
```

끝나면 Xcode 가 알려 주는 대로:

1. Xcode 실행 → **Window → Organizer** → Archives 에 방금 만든 `Runner` 가 보입니다
   (안 보이면 `open build/ios/archive/Runner.xcarchive`)
2. **Distribute App** → **App Store Connect** → **Upload** → Next
3. 서명은 **Automatically manage signing** 그대로 → Upload
   (이때 애플 ID 비밀번호나 키체인 암호를 물어보면 직접 입력하세요)
4. 10~30분 뒤 App Store Connect → TestFlight 에 빌드가 올라옵니다
   ("ITMS-91053" 같은 메일이 오면 개인정보 매니페스트 문제인데, `PrivacyInfo.xcprivacy` 를
   이미 넣어 두었으므로 보통 오지 않습니다)

> Xcode 에서 직접 하려면: `open ios/Runner.xcworkspace` → 기기 선택을
> **Any iOS Device (arm64)** 로 → Product → Archive.

### App Store Connect 에 채울 것

| 칸 | 값 |
|---|---|
| 이름 | 기추리 |
| 부제 | 내 자료로 뽑는 예상 기출 |
| 카테고리 | 교육 |
| 개인정보처리방침 URL | `https://gichul.site/privacy` |
| 지원 URL | `https://gichul.site` |
| 연령 등급 | 4+ (폭력·성적 내용 없음) |
| 암호화 | 따로 묻지 않습니다 (`ITSAppUsesNonExemptEncryption = NO` 를 넣어 두었습니다) |

스크린샷은 6.9형 아이폰과 13형 아이패드가 필요합니다. 시뮬레이터에서 찍으면 규격이 맞습니다:

```bash
xcrun simctl boot "iPhone 17 Pro Max"; open -a Simulator
# 앱에서 화면을 띄워 놓고
xcrun simctl io booted screenshot ~/Desktop/1-출제하기.png
```

## 2. 심사 메모 (App Review Notes) — 그대로 붙여 넣기

```
기추리는 학생이 자기 공부자료(PDF·PPTX·사진)를 올리면 그 내용으로 예상 기출문제를
만들어 주는 학습 앱입니다.

[로그인 없이 바로 확인하실 수 있습니다]
- 첫 화면 오른쪽 위 "게스트로 시작"을 누르면 계정 없이 모든 기능을 쓸 수 있습니다.
- 문제집 탭 > "예시 시험지 둘러보기"에 미리 만들어 둔 시험지가 있어, 자료를 올리지 않고도
  문제 풀이·채점·해설·오답노트를 확인하실 수 있습니다.
- 자료를 직접 올려 보시려면 아무 PDF나 사진을 올리고 "출제 요청 보내기"를 누르시면
  1~2분 뒤 문제집 탭에 시험지가 올라옵니다.

[이 앱만의 기능]
- 시험지 공유: 시험지를 txt 파일이나 링크로 iOS 공유 시트를 통해 내보냅니다.
- 인쇄·PDF 저장: iOS 인쇄 화면으로 시험지를 인쇄하거나 PDF로 저장합니다.
- 카메라·사진: 필기나 교재를 찍어 바로 자료로 올립니다.
- 당겨서 새로고침, 시험지 완성 푸시 알림(출제가 끝나면 알려 드립니다).

[계정 삭제]
앱 안에서 하단 "개인정보처리방침" > "계정 삭제" 버튼으로 계정과 기록을 모두 지울 수 있습니다.
(https://gichul.site/privacy)

[애플 로그인]
구글 로그인이 있어 가이드라인 4.8에 따라 애플 로그인도 함께 제공합니다. 앱 안에서는
"애플로 로그인" 버튼이 보입니다.
```

영어로도 넣어 두면 좋습니다:

```
Gichuri turns a student's own study material (PDF, PPTX, photos) into practice exam questions.

No account is needed to review the app: tap "게스트로 시작" (Start as guest) on the first
screen, or open 문제집 (Library) > "예시 시험지 둘러보기" to try a pre-made sample exam
with grading, explanations and the mistake notebook.

Native features: iOS share sheet (export an exam as a text file or link), AirPrint /
Save-as-PDF, camera & photo upload of handwritten notes, pull-to-refresh, and push
notifications when an exam finishes generating.

Account deletion is available inside the app: Privacy Policy page > "계정 삭제".

Sign in with Apple is offered alongside Google sign-in (guideline 4.8).
```

### 거절이 잦은 항목에 대한 준비

- **4.8 (로그인 선택권)**: 애플 로그인 제공 + 로그인 없이 쓰는 "게스트로 시작" 둘 다 있습니다.
- **4.2 (웹사이트 포장 앱)**: 공유·인쇄/PDF·카메라 업로드·당겨서 새로고침·푸시 알림이
  네이티브로 들어 있습니다. 심사 메모에 이 목록을 꼭 남기세요.
- **5.1.1(v) (계정 삭제)**: 앱 안 `/privacy` 페이지에 계정 삭제 버튼이 있고, 앱에서 그 페이지로
  가는 길이 막혀 있지 않습니다(같은 사이트라 웹뷰 안에서 열립니다).
- **2.1 (정보 부족)**: 심사자가 실제 시험지를 보도록 "예시 시험지"를 안내해 두었습니다.

## 3. 앱 개인정보 (App Privacy) 응답표

App Store Connect → 앱 → 앱 개인정보. **추적(Tracking)은 모두 "아니요"** 입니다.

| 데이터 | 수집 | 앱 기능 목적 | 사용자와 연결 | 추적 |
|---|---|---|---|---|
| 연락처 정보 → 이메일 주소 | 예 (구글·애플 로그인 시) | 예 | 예 | 아니요 |
| 식별자 → 사용자 ID | 예 | 예 | 예 | 아니요 |
| 식별자 → 기기 ID | 예 (알림용 토큰) | 예 | 예 | 아니요 |
| 사용자 콘텐츠 → 기타 사용자 콘텐츠 | 예 (올린 공부자료의 글·그림) | 예 | 예 | 아니요 |

- 그 밖의 항목(위치, 연락처, 건강, 금융, 검색 기록, 광고 데이터 등)은 모두 **수집하지 않음**
- 분석·광고 SDK 는 넣지 않았습니다 (Firebase 는 알림 기능만 씁니다)
- 이 표는 `ios/Runner/PrivacyInfo.xcprivacy` 와 같은 내용입니다

## 4. 안드로이드 — 플레이 스토어

```bash
flutter build appbundle    # app/gichuri 안에서 · build/app/outputs/bundle/release/app-release.aab
```

1. Play Console → 앱 만들기 → 이름 `기추리`, 언어 한국어, 앱, 무료
2. **내부 테스트**부터 올려서 직접 설치해 보기를 권합니다
3. 채울 것
   - 개인정보처리방침: `https://gichul.site/privacy`
   - 앱 카테고리: 교육
   - 콘텐츠 등급 설문
   - 타겟 연령: 만 14세 이상 (방침과 맞춤)
   - **데이터 보안** 양식: 아래 표
   - **계정 삭제**: "앱에서 계정을 삭제할 수 있음" + 웹 주소 `https://gichul.site/privacy`

### 데이터 보안 양식

| 항목 | 수집 | 공유 | 필수 | 목적 |
|---|---|---|---|---|
| 개인 정보 → 이메일 주소 | 예 | 아니요 | 선택 (로그인할 때만) | 계정 관리 |
| 개인 정보 → 사용자 ID | 예 | 아니요 | 필수 | 계정 관리, 앱 기능 |
| 파일 및 문서 | 예 | 아니요 | 선택 | 앱 기능 (문제 만들기) |
| 기기 또는 기타 ID | 예 | 아니요 | 선택 | 앱 기능 (알림) |

- 전송 중 암호화: **예** · 데이터 삭제 요청 가능: **예**
- "공유"는 외부 업체에 **처리를 맡기는 것**(Supabase·Anthropic)은 포함되지 않습니다.
  위탁 내용은 개인정보처리방침 3번에 적혀 있습니다.
