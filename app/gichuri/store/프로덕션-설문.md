## 5. 앱의 주요 대상은 누구인가요?

1. 시험을 앞두고 강의자료(PDF·PPTX)나 필기 사진을 가지고 있는 대학생·고등학생
2. 기출문제가 공개되지 않는 과목을 듣고 있어 풀어 볼 문제가 없는 사람
3. 요약정리만 반복하다 정작 문제를 못 풀어 보고 시험장에 들어가는 사람
4. 틀린 문제를 모아 두고 간격을 두고 다시 풀고 싶은 사람
5. 같은 과목을 듣는 친구들과 같은 시험지를 풀고 점수를 비교해 보고 싶은 사람
6. 수식이 들어간 이공계 과목을 공부하는 사람

연령대는 만 16세 이상으로 설정했습니다.

## 6. 앱이 사용자에게 어떤 가치를 제공하는지 설명하세요.

기존 문제집이나 문제은행은 남이 만든 문제라 내 수업 범위와 어긋납니다. 기추리는
**본인이 올린 자료 안에서만** 문제를 만들기 때문에, 실제로 시험에 나올 범위에서
문제가 나옵니다. 교수가 올린 강의노트를 그대로 넣으면 그 자료로 시험지가 됩니다.

다른 점은 이렇습니다.

- **해설에 근거가 붙습니다.** 각 문제의 해설에 그 근거가 된 파일 이름과 쪽수가
  적혀 있어서, 틀린 문제를 교재의 어느 쪽으로 돌아가 봐야 하는지 바로 알 수 있습니다.
- **오답노트가 간격을 두고 다시 물어봅니다.** 틀리면 그날, 맞히면 1일 뒤, 또 맞히면
  3일 뒤에 다시 나오고 세 번 맞히면 목록에서 빠집니다.
- **시험 모드**가 있어 제한 시간을 걸고 실전처럼 풀 수 있고, 시간이 끝나면 자동 채점됩니다.
- **시험지를 링크로 공유**하면 친구도 같은 시험지를 풀고, 푼 사람끼리 점수가 비교됩니다.
- **인쇄와 PDF 저장**이 되어 종이로 풀 수도 있습니다.
- 수학·공학 과목의 **수식이 깨지지 않습니다.**
- **가입하지 않아도** 바로 쓸 수 있고, 나중에 계정을 연결하면 그동안의 기록이 따라옵니다.

## 8. 비공개 테스트에서 알게 된 내용을 바탕으로 앱을 어떻게 변경했나요?

[채울 것 — 테스트 기간에 실제로 올린 변경만 쓴다. 버전을 2번 이상 올렸다면
 각각 무엇을 고친 버전인지 쓰는 것이 좋다.]

아래는 테스트 기간 전후로 실제로 반영한 것들이라 사실대로 쓸 수 있는 항목이다.
해당하는 것만 남기고 나머지는 지운다.

- 처음 들어온 사람이 자료를 올리기 전에는 앱이 무엇을 만들어 주는지 볼 수 없다는
  문제가 있었습니다. 첫 화면에 과목이 다른 예시 시험지 세 개를 올려, 자료를 올리지
  않아도 결과물을 먼저 보고 풀어 볼 수 있게 했습니다.
- 강의자료를 올리는 앱이다 보니 올린 자료가 어떻게 처리되는지 불안하다는 점이
  있어, 첫 화면에 "원본 파일은 기기에만 둡니다 · 출제에 쓴 내용은 14일 뒤 자동 삭제 ·
  AI 학습에는 쓰지 않습니다"를 적고 개인정보처리방침으로 연결했습니다.
- 시작할 때 '게스트로 시작'과 '로그인' 중 하나를 고르게 되어 있어 첫 사용이
  불필요하게 한 단계 길었습니다. 게스트를 기본값으로 바꿔, 아무것도 고르지 않고
  바로 자료를 올려 쓸 수 있게 했습니다.
- 출제가 1~2분 걸리는데 그동안 창을 닫으면 결과를 놓치는 문제가 있어, 시험지가
  완성되면 기기 알림으로 알려 주도록 했습니다.

## 9. 앱이 프로덕션용으로 준비되었다고 어떻게 판단했나요?

같은 기능을 웹사이트로 먼저 공개해 운영하면서 실제 요청을 처리해 왔습니다.
[채울 것 — 신청 시점의 숫자로 갱신] 현재까지 들어온 출제 요청 가운데 대부분이
정상적으로 시험지까지 만들어졌고, 실패한 요청은 극소수입니다. 자료를 읽어 문제를
만들고 채점·해설까지 가는 전체 흐름이 끊기지 않고 돌아간다는 것을 확인했습니다.

앱에 대해서는 실제 기기에 설치해 다음을 직접 확인했습니다.

- 구글·애플 계정 로그인과, 게스트로 쓰던 기록이 로그인 계정으로 이어지는 것
- 출제 완료 알림이 실제 기기로 도착하는 것
- 시험지 공유와 인쇄·PDF 저장
- 사진·카메라로 자료를 올리는 것
- 인터넷이 끊겼을 때 안내 화면이 뜨고, 연결되면 다시 이어지는 것

남용과 비용 문제에 대해서도 대비해 두었습니다. 로그인하지 않은 사용자, 계정별,
같은 네트워크별, 사이트 전체에 각각 하루 요청 한도를 두어 특정 사용자나 갑작스러운
유입으로 서비스가 중단되지 않도록 했습니다.

계정 삭제는 앱 안의 개인정보처리방침 화면에서 직접 할 수 있고, 삭제하면 계정과
그동안의 기록이 함께 지워집니다.

앞으로도 사용자 의견을 받아 계속 고쳐 나갈 수 있는 상태라고 판단해 프로덕션을
신청합니다.
