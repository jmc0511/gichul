# 스토어 스크린샷 다시 찍기

사이트 화면이 바뀌었을 때 같은 방법으로 다시 찍으면 됩니다. 결과는 `~/Desktop/기추리-스토어/` 에 쌓입니다.

## 1. 장면 전환 스크립트 넣기 (임시)

`app/gichuri/tool/shot-driver.js` 내용을 `lib/web_shell.dart` 에 `UserScript` 로 하나 더 넣고,
웹뷰의 `initialUserScripts` 를 `[_shim, _shotDriver]` 로 바꿉니다. (찍고 나면 꼭 되돌리세요 —
`git checkout app/gichuri/lib/web_shell.dart`)

스크립트는 페이지가 뜬 뒤 이 순서로 화면을 움직입니다.

| 초 | 하는 일 | 찍히는 장면 |
|---|---|---|
| 3 | 사용법 안내 닫기 | ① 자료 올리기 |
| 11 | 출제 조건까지 스크롤 | ② 출제 조건 |
| 19 | 문제집 → 예시 시험지 열기 | ③ 시험지 |
| 27~31 | 정답 고르고 채점(하나는 일부러 틀리게) + 자가채점 | ④ 채점·해설 |
| 38 | 답안지 열기 | ⑤ 답안지 |

## 2. 아이폰 6.9형 (1320 × 2868)

```bash
cd app/gichuri && flutter build ios --simulator --debug
D=$(xcrun simctl list devices available | grep "iPhone 17 Pro Max" | grep -o "[0-9A-F-]\{36\}")
OUT=~/Desktop/기추리-스토어/앱스토어-아이폰6.9; mkdir -p "$OUT"
xcrun simctl boot $D; sleep 12
xcrun simctl install $D build/ios/iphonesimulator/Runner.app
xcrun simctl launch --terminate-running-process $D site.gichul.app
sleep 9;  xcrun simctl io $D screenshot "$OUT/1-자료올리기.png"
sleep 8;  xcrun simctl io $D screenshot "$OUT/2-출제조건.png"
sleep 8;  xcrun simctl io $D screenshot "$OUT/3-시험지.png"
sleep 11; xcrun simctl io $D screenshot "$OUT/4-채점해설.png"
sleep 9;  xcrun simctl io $D screenshot "$OUT/5-답안지.png"
```

## 3. 아이패드 13형 (2064 × 2752)

위와 같고 기기만 `iPad Pro 13-inch (M5)` 로, 폴더는 `앱스토어-아이패드13` 로 바꿉니다.
**첫 부팅 직후에는 로딩이 느려 장면이 어긋납니다.** 한 번 띄워 둔 뒤 다시 찍으세요.

## 4. 안드로이드 휴대전화 (1080 × 1920)

```bash
~/Library/Android/sdk/emulator/emulator -avd gichuri_shot -no-window -no-audio -gpu swiftshader_indirect &
export PATH=$PATH:~/Library/Android/sdk/platform-tools
cd app/gichuri && flutter build apk --debug
OUT=~/Desktop/기추리-스토어/플레이-휴대전화; mkdir -p "$OUT"
adb install -r build/app/outputs/flutter-apk/app-debug.apk
adb shell am start -n site.gichul.app/.MainActivity
sleep 12; adb exec-out screencap -p > "$OUT/1-자료올리기.png"
sleep 8;  adb exec-out screencap -p > "$OUT/2-출제조건.png"
sleep 8;  adb exec-out screencap -p > "$OUT/3-시험지.png"
sleep 11; adb exec-out screencap -p > "$OUT/4-채점해설.png"
sleep 9;  adb exec-out screencap -p > "$OUT/5-답안지.png"
```

에뮬레이터 `gichuri_shot` 은 Pixel 2(1080×1920, 16:9)로 만들어 두었습니다.
Play 는 가로:세로 비율이 2:1 을 넘으면 안 받으므로 최신 기기 비율(20:9)로는 찍지 마세요.
