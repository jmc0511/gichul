- 다크 배경 `#0f1218`, 포인트 `#cf3f63` (스플래시: flutter_native_splash, 배경색 + 아이콘)

## 구조: 웹뷰 + 네이티브 기능
`flutter_inappwebview` 로 `https://gichul.site/#make` 를 전체 화면에 띄워. 사이트가 safe-area 를 직접 처리하니 SafeArea 로 감싸지 말고 웹뷰가 화면 끝까지 차게.
- **User-Agent**: 기본 UA 끝에 ` GichuriApp/1.0` 을 붙여 (`applicationNameForUserAgent`). 사이트가 이걸 보고 앱 모드(설치 배너 숨김, 애플 로그인 버튼 표시, 아래 핸들러 사용)로 바뀜
- 설정: JavaScript·DOM storage·IndexedDB 켬, `allowsInlineMediaPlayback`, `allowsBackForwardNavigationGestures: true`, 줌 끔, 당겨서 새로고침(PullToRefreshController)
- **이동 제한**: `gichul.site`, `*.supabase.co` 만 웹뷰 안에서 열고, 나머지(카카오페이 `qr.kakaopay.com`, `mailto:` 등)는 `url_launcher` 로 사파리/외부 앱에서 열어. `target=_blank` / `window.open` 도 같은 규칙
- **파일 올리기**: `<input type=file>` 은 WKWebView 가 사진 보관함·카메라·파일 선택을 띄움. Info.plist 에 `NSPhotoLibraryUsageDescription`("공부자료 사진을 올리려면 사진 접근이 필요해요"), `NSCameraUsageDescription`("필기·교재를 찍어 올리려면 카메라가 필요해요") 넣고 실제로 PDF·PPTX·사진 선택이 되는지 확인
- **오프라인/오류**: 첫 로드 실패 시 네이티브 화면("인터넷에 연결되지 않았어요" + 다시 시도)

## 사이트가 부르는 JS 핸들러 (이름·인자 그대로 맞춰야 함)
사이트는 `window.flutter_inappwebview.callHandler(이름, 인자)` 로 부르고 결과를 기다려. `addJavaScriptHandler` 로 등록해:
1. **`oauth`** (인자: 로그인 URL 문자열) → `flutter_web_auth_2` 로 `ASWebAuthenticationSession` 을 열고 callbackUrlScheme `gichuri`, 돌아온 전체 URL(`gichuri://auth?code=...` 또는 `...#error_description=...`)을 **문자열 그대로** 반환. 사용자가 취소하면 `null`. (구글은 웹뷰 안 로그인을 막아서 이렇게 해야 함. 사이트가 받은 code 로 세션을 만듦)
   - Info.plist `CFBundleURLTypes` 에 스킴 `gichuri` 등록
2. **`print`** (인자 없음) → 지금 웹뷰 페이지를 iOS 인쇄 창으로 (`controller.printCurrentPage()`), 인쇄 창이 닫히면 반환. PDF 저장도 이 창에서 됨
3. **`share`** (인자: `{url, title}` 또는 `{text, filename}`) → `share_plus` 로 공유 시트. `{text, filename}` 이면 임시 폴더에 그 이름의 UTF-8 txt 파일을 만들어 파일로 공유. iPad 는 sharePositionOrigin 지정

## App Store 심사 대비 (중요)
- 4.8: 구글 로그인이 있으니 **애플 로그인**이 필요 → 사이트가 앱 안에서만 "애플 로그인" 버튼을 보여 주고 같은 `oauth` 핸들러로 Supabase Apple 로그인을 함. Supabase 쪽 Apple 설정은 내가 할 거니, 필요한 값(Services ID, Key ID, Team ID, .p8 키, Return URL)을 단계별로 정리해 줘
- 4.2(웹사이트 포장 앱 거절): 네이티브 가치로 위의 공유·인쇄·카메라 업로드·당겨서 새로고침을 넣었고, 다음 단계로 APNs 푸시(시험지 완성 알림)를 붙일 예정. 심사 메모(App Review Notes) 문안도 써 줘: 게스트로 시작하면 로그인 없이 써 볼 수 있음, 예시 시험지 있음
- 5.1.1(v) 계정 삭제: 사이트의 개인정보처리방침 페이지(`/privacy`)에 계정 삭제가 있음 → 앱 안에서 거기까지 가는 경로가 막히지 않는지 확인
- 개인정보: `PrivacyInfo.xcprivacy` 작성(수집: 이메일·사용자 ID(로그인 시), 사용자 콘텐츠(올린 자료), 추적 없음). 앱스토어 "앱 개인정보" 응답표도 정리해 줘
- 암호화: `ITSAppUsesNonExemptEncryption = NO`
